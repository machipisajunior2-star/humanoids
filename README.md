# Humanoids

## Description

> Humanoids is a public learning resource for anyone interested in the future of robotics.
> The project brings together clear explanations, visual references, technical articles, beginner-friendly guides, and news about humanoid robots. Its goal is to connect the ideas behind humanoid robotics with the practical skills needed to understand how these machines are designed, programmed, and controlled.
> A humanoid robot generally resembles the human body, often combining a torso, head, arms, and legs. This form is useful because humanoids are designed to operate in environments built for people and, in some cases, interact with tools made for human use.
> Humanoids explores both the possibilities and the challenges of this field, from walking and balance to computer vision, artificial intelligence, manipulation, and human–robot interaction.
> What you can explore:

- Humanoid robot fundamentals — Learn what defines a humanoid robot, how different designs vary, and why researchers and companies continue to develop them.
- Robot components — Explore sensors, cameras, microphones, actuators, motors, control systems, batteries, and the software that connects these parts.
- How humanoids move — Understand the role of perception, motion planning, balance, trajectory control, obstacle avoidance, and whole-body coordination.

## Learning objectives

- Create a semantic React web application that presents a humanoid-robotics topic using headings, sections, links, images, captions, and meaningful alternative text.
- Explain the relationship between JSX, JavaScript, components, props, and state by using them to create an interactive interface about humanoid robotics.
